# Expense Tracker (Python)
A simple command-line Expense Tracker application built with Python.  
This project allows users to add, view, summarize, and delete expenses while storing data in a JSON file.

## Features
- Add new expenses
- View all expenses
- View expense summary by category
- Delete expenses by ID
- Automatic data saving using JSON
- Simple and beginner-friendly CLI interface

## Technologies Used
- Python 3
- JSON file handling
- Datetime module
